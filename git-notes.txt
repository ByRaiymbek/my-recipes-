git restore - востонавливает до последнего коммита, 
можно легко отменить но только незакоммиченные
git checkout <хеш> - Переключает состояние репозитория
на конкретный коммит из истории для его просмотра или теста
HEAD detached - состояние репозитория
git revert - отменяет все изменение последнего коммита
и эту отмену создает как новый коммит
git switch -c - создает новую ветку и сразу переключается на нее
git merge - обьеденияет изменения из одной ветки в другую
fast-forward -  тип слияния веток, при котором целевая ветка
 просто «передвигается» вперед до коммита сливаемой ветки без создания нового коммита слияния.
git branch -d - удаляет указанную локальную ветку
